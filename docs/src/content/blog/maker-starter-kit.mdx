## Introducción

Este post es un ejemplo práctico que utiliza todos los campos nuevos pensados para posts de electrónica e impresión 3D. Sirve como plantilla para tus propios proyectos "maker".

## Objetivo del proyecto

Crear un soporte impreso en 3D para un sensor de temperatura que se conecta a un microcontrolador. El diseño del soporte está en CAD y el modelo imprimible está disponible como STL.

## Electrónica: esquema básico

- Microcontrolador: ESP32
- Sensor: DS18B20 (o similar)
- Resistencias, cables dupont y protoboard
